# 05 · IPv6 Essentials

You cannot avoid IPv6 anymore. Cloud providers hand it out by default, mobile carriers run
it, and every certification expects it. Good news: the concepts are the same. Only the
notation and a few mechanisms change.

## Why IPv6 exists

IPv4 has about 4.3 billion addresses. That ran out. NAT stretched it for decades, but NAT
breaks end-to-end connectivity, complicates VoIP and peer-to-peer, and does not scale to
billions of devices.

IPv6 has **340 undecillion** addresses (2^128). Enough to give every grain of sand an address.

## The address format

Eight groups of four hex digits, separated by colons.

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

### Two compression rules

1. **Drop leading zeros** in each group: `0db8` → `db8`, `0000` → `0`.
2. **Replace one run of all-zero groups with `::`** — only once per address.

```
2001:0db8:0000:0000:0000:0000:0000:0001
-> 2001:db8::1
```

### The /64 rule

A standard LAN is a **/64**. That leaves 64 bits for hosts — more than enough for SLAAC.
Do not use longer prefixes for LANs; SLAAC requires /64.

## Address types

| Prefix | Type | Use |
|---|---|---|
| `2000::/3` | Global unicast | routable on the Internet |
| `fe80::/10` | Link-local | every interface, auto-generated, not routed |
| `fc00::/7` | Unique local (ULA) | like RFC1918 private space |
| `ff00::/8` | Multicast | replaces broadcast |
| `::1/128` | Loopback | localhost |
| `::/0` | Default route | everything else |

**There is no broadcast in IPv6.** Multicast (and anycast) replace it.

Common multicast addresses:

| Address | Meaning |
|---|---|
| `ff02::1` | all nodes on the link |
| `ff02::2` | all routers on the link |
| `ff02::5` | OSPFv3 routers |
| `ff02::1:ff00:0/104` | solicited-node (used by NDP) |

## How a host gets an address

Two mechanisms, often both:

**1. SLAAC (Stateless Address Autoconfiguration)**
- Host sends a Router Solicitation to `ff02::2`
- Router replies with a Router Advertisement containing the /64 prefix
- Host builds its own address (EUI-64 or privacy extension) and does Duplicate Address Detection

**2. DHCPv6**
- Stateful: server assigns addresses (like DHCPv4)
- Stateless: server only gives DNS and other options; address comes from SLAAC

Most enterprise networks use **SLAAC + stateless DHCPv6** or DHCPv6 stateful, depending
on the vendor and policy.

## NDP replaces ARP

**Neighbor Discovery Protocol** does what ARP, ICMP redirect, and router discovery did in IPv4.

| Message | Purpose |
|---|---|
| Router Solicitation / Advertisement | find routers and prefixes |
| Neighbor Solicitation / Advertisement | resolve a link-layer address (ARP replacement) |
| Duplicate Address Detection | is this address already in use? |
| Redirect | better next hop available |

NDP runs over ICMPv6. **If you block ICMPv6, you break IPv6.** This is the number one
IPv6 firewall mistake.

## What changed from IPv4

| IPv4 | IPv6 |
|---|---|
| ARP | NDP (ICMPv6) |
| Broadcast | Multicast only |
| DHCP | SLAAC / DHCPv6 |
| NAT everywhere | NAT is the exception, not the rule |
| Header with options | Fixed 40-byte header + extension headers |
| Fragmentation by routers | Only the source fragments |
| Manual/automatic addressing | Automatic by design |

## Dual stack and transition

The practical migration is **dual stack**: run IPv4 and IPv6 on the same interface.

```
Cisco:  ipv6 unicast-routing
        interface Gi0/1
         ipv6 address 2001:db8:1::1/64
         ipv6 address fe80::1 link-local
```

Other transition tools you will hear about:

- **NAT64/DNS64** — IPv6-only clients reach IPv4 servers
- **6to4 / Teredo** — legacy tunnels, mostly dead
- **DS-Lite / MAP-T** — carrier-grade IPv4-over-IPv6

## Common pitfalls

| Pitfall | Result |
|---|---|
| Blocking ICMPv6 | NDP breaks, nothing works |
| Using /48 or /56 on a LAN | SLAAC breaks |
| Forgetting link-local for routing protocols | OSPFv3/BGP neighbors fail |
| Assuming no NAT means no firewall | Wrong — stateful firewalls still needed |
| Using `::` carelessly in configs | valid but usually means "unspecified" |
