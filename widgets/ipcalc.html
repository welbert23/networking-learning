The AND operation

The network address is the IP address AND the subnet mask, bit by bit. 1 AND 1 = 1. Everything else = 0.

What each bit is worth

The 30-second method
  1. Block size = 256 − the mask octet in the interesting octet (e.g. 192 → 64).
  2. Network = the highest multiple of the block size that is ≤ your address.
  3. Broadcast = the next block start − 1.
  4. Usable = network + 1 through broadcast − 1.
  5. Hosts = 2(32 − prefix) − 2.

Hextet breakdown

Each of the 8 groups is 16 bits. Hex digit → 4 bits. Two bytes per group.

128 bits

IPv6 compression rules (RFC 5952)
  1. Drop leading zeros in each group: 0db8 → db8.
  2. Replace one run of two or more all-zero groups with ::.
  3. If there is a tie, compress the first run.
  4. Never use :: more than once in an address.
  5. Never shorten a single zero group — write 0, not ::.
IPv6 planning rules
  • /32 to an ISP, /48 to a site, /56 to a home or small branch.
  • /64 for every LAN — SLAAC requires the host part to be 64 bits.
  • /128 for a single interface (loopback, host route).
  • /127 for point-to-point links (RFC 6164) — avoids the all-zeros subnet-router anycast address.

MAC address to EUI-64 (SLAAC)

Flip the universal/local bit of the first octet, then insert ff:fe in the middle. That is the interface ID a router gives you in a Router Advertisement.

How VLSM works
  1. Sort the requirements from biggest to smallest.
  2. Host bits = the smallest n where 2n − 2 ≥ hosts.
  3. Prefix = 32 − n. That is the subnet size.
  4. Place it at the next free address that is aligned to its own block size.
  5. Repeat. If a block does not fit, the plan is over-committed.

Why /64 is the default LAN size
  • SLAAC needs 64 host bits, so every LAN is a /64 even if it has five devices.
  • One /48 gives you 65,536 /64 LANs — that is the site allocation.
  • Subnet bits are the bits between the site prefix and /64. Change those, never the interface ID.
